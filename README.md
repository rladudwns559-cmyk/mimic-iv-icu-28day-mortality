# MIMIC-IV 성인 중환자실 환자의 28일 사망 위험 예측

데이터사이언스를 위한 프로그래밍 · 1트랙 2팀 (김영준 · 전서영 · 성영주 · zin zin nyein)

**연구 질문.** 성인 환자의 첫 ICU 입실 후 24시간 동안 기록된 정보로 입실 후 28일 이내 사망을 예측할 수 있는가?

> 이 저장소에는 **코드와 실행 방법만** 있습니다. MIMIC-IV 원자료, 환자 단위 파생 자료(코호트·전처리·분할·예측 파일),
> 학습된 모델 파일은 데이터 이용 협약(DUA)에 따라 올리지 않았습니다.
> 대시보드는 **교육용 연구 모델이며 실제 진료에 사용할 수 없습니다.**

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 자료 | MIMIC-IV 3.1, Beth Israel Deaconess Medical Center 2008–2019년 |
| 분석 대상 | 성인 환자별 첫 ICU 입실 30,112명 (28일 사망 6,697명, 22.2%) |
| 예측 시점 | 첫 ICU 입실 후 24시간 (그 시점에 ICU에 있는 환자) |
| 입력 | 나이·성별, 활력징후 7종, 혈액검사 12종의 첫 24시간 집계값과 측정 여부, 첫 ICU 유형 (150개) |
| 최종 모델 | XGBoost · 결측값 대체 없음 + 결측 지시변수 + 젖산 + 첫 ICU 유형 |
| 테스트 성능 (4,517명) | ROC-AUC 0.819 (95% CI 0.804–0.833) · AP 0.580 (0.548–0.611) · Brier 0.131 (0.125–0.137) |

## 연구 진행 과정

### 1. 연구 대상 정하기
원자료의 ICU 입실 94,458건(환자 65,366명)에서 환자마다 첫 입실만 남겼습니다(18세 미만 0명).
24시간 시점에 ICU에 없는 13,725명(그 전에 퇴실 12,314명, 사망 1,379명, 시각 불명확·기록 오류 32명)을 제외했고,
28일 생존 여부를 기록으로 확정할 수 없는 21,529명은 생존으로 간주하지 않고 제외해 30,112명을 분석했습니다.
28일 사망 여부로 층화해 학습 70% · 검증 15% · 테스트 15%로 나누고(random_state 42),
학습과 검증을 합친 25,595명을 개발 자료로, 테스트 4,517명(사망 1,005명)은 최종 평가에만 썼습니다.

### 2. 입력 변수 만들기
APACHE II · SAPS II · SOFA의 항목을 참고해 활력징후 7종(심박수, 호흡수, 산소포화도, 수축기·이완기 혈압, 평균동맥압, 체온)과
혈액검사 12종(크레아티닌, 혈당, 나트륨, 칼륨, 중탄산염, 음이온차, 헤모글로빈, 헤마토크릿, 백혈구, 혈소판, INR, 젖산)을 골랐습니다.
항목마다 첫 24시간의 평균 · 최솟값 · 최댓값 · 표준편차 · 측정 횟수 · 측정 여부를 만들었습니다.
간기능 검사 3종(ALT · AST · 총빌리루빈)은 약 50%가 결측이고 세 검사가 모두 빠진 환자가 49.2%여서 제외했습니다.
명백한 기록 오류(심박수 500회/분 초과 등)인 활력징후 관측 176건만 지웠고, 이 때문에 빠진 환자는 없습니다.

### 3. 결측 다루기
검사를 하지 않은 환자는 사망률이 낮았습니다(젖산 측정 26.0% vs 미측정 16.2%). 검사 여부가 환자 상태와 진료 판단을 반영하므로,
결측 여부를 지시변수로 입력에 넣고 결측이 많은 환자도 빼지 않았습니다. 남은 빈 값은 중앙값 대체, MICE(대체 자료 5개),
대체 없음(XGBoost가 결측 방향을 학습) 세 방식으로 비교했습니다.

### 4. 모델 비교
개발 자료의 같은 층화 5개 폴드에서 로지스틱 회귀(L2), 랜덤 포레스트, XGBoost를 비교했습니다.
고정 설정 비교와 5×3 중첩 교차검증(안쪽 3폴드로 설정 선택, 바깥 5폴드로 평가) 모두에서 XGBoost가 가장 높았고,
같은 환자의 교차검증 예측으로 구한 차이는 랜덤 포레스트 대비 AP +0.029 (95% CI +0.022 – +0.035),
로지스틱 회귀 대비 AP +0.074 (95% CI +0.065 – +0.084)였습니다.

| 모델 (중첩 교차검증, 폴드 평균 ± SD) | ROC-AUC | AP |
|---|---|---|
| 로지스틱 회귀 | 0.780 ± 0.007 | 0.508 ± 0.011 |
| 랜덤 포레스트 | 0.806 ± 0.006 | 0.562 ± 0.006 |
| XGBoost | 0.822 ± 0.007 | 0.589 ± 0.014 |

### 5. 결측 처리 · 젖산 · 첫 ICU 유형
XGBoost 설정을 고정하고 입력 조건을 바꿔 비교했습니다.
- 대체 없음(AP 0.590)과 MICE(0.589)는 비슷해서, 모델 하나로 예측할 수 있는 대체 없음을 택했습니다.
- 젖산 수치를 측정 여부에 더하면 AP가 +0.006 (95% CI +0.003 – +0.009) 높았습니다.
- 첫 ICU 유형을 더하면 AP가 0.013 높았고 5개 폴드 모두에서 양수였습니다. Neuro SICU의 평균 예측이 28.0%에서 49.2%로 실제 사망률(52.6%)에 가까워졌습니다.
- 결측 지시변수 38개를 뺀 민감도 분석은 AP 0.588로 기준 모델(0.590)과 비슷했습니다.

### 6. 최종 평가
최종 모델을 개발 자료 전체로 다시 학습해 테스트 자료에서 한 번 평가했습니다(신뢰구간은 테스트 환자 부트스트랩 2,000회).
첫 ICU 유형을 뺀 같은 모델보다 ROC-AUC +0.007 (+0.003 – +0.012), AP +0.016 (+0.006 – +0.024) 높았습니다.

| 경보 기준 | 민감도 | 놓친 사망 | 특이도 | 양성예측도 |
|---|---|---|---|---|
| 0.5 | 35.2% (354/1,005) | 651명 | 94.4% | 64.5% |
| 0.3 | 61.0% (613/1,005) | 392명 | 83.7% | 51.7% |

모델은 사망 위험의 순서를 구분했지만 기준 0.5에서는 사망 환자 3명 중 2명을 놓쳤습니다.

### 7. 교육용 대시보드
저장한 최종 모델을 불러 쓰기만 하는 Gradio 화면을 만들었습니다. 첫 24시간 측정값을 넣으면 28일 사망 확률,
기준 30% · 50%의 경보 여부, 항목별 SHAP 기여도를 보여 줍니다. 화면 입력을 모델 입력으로 바꾸는 규칙은 테스트 4,517명 전원으로 검증했습니다.

### 한계
테스트 자료를 이전 모델 평가에도 사용했고, 한 병원 자료이며, 기준 0.3은 학습 자료에서 최적화한 값이 아닙니다.
28일 결과를 확정하지 못해 제외한 환자는 더 젊고 모두 생존 퇴원해, 분석 대상은 중증 쪽에 치우쳐 있습니다.
측정 여부와 측정 횟수는 의료진의 판단을 담을 수 있어 다른 병원에서는 성능이 달라질 수 있습니다.

## 실행 방법

Python 3.12

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

| 순서 | 명령 | 하는 일 | 시간(참고) |
|---|---|---|---|
| 1 | `python scripts/01_make_cohort.py` | 성인 첫 ICU 입실, 24시간 관찰, 28일 결과 확정 조건으로 코호트 생성 | 미측정 |
| 2 | `python scripts/run_pipeline.py` | 활력징후 7종 · 혈액검사 12종 추출, 첫 24시간 변수 생성 | 약 43분 |
| 3 | `python scripts/clean_gross_errors.py` | 명백한 기록 오류 활력징후 관측 제거(176건) | 미측정 |
| 4 | `python scripts/split_dataset.py` | 층화 70/15/15 분할 (random_state 42) | 미측정 |
| 5 | `python scripts/reproduce_final_icu_xgboost.py` | 최종 XGBoost 재학습과 테스트 평가 | 미측정 |

시간은 팀원 노트북(Windows 11) 한 대에서 잰 값이며, 재지 않은 단계는 미측정으로 두었습니다.
5번까지 실행하면 테스트 4,517명에서 ROC-AUC 0.819, AP 0.580, Brier 0.131이 나옵니다.

### 개발 단계 비교 실험

```powershell
python scripts/train_three_models_cv.py              # 세 모델 고정 설정 비교 (5-fold)
python scripts/compare_three_models_imputation_cv.py # 중앙값 vs MICE 대체
python scripts/tune_three_models_nested_cv.py        # 5×3 중첩 교차검증
python scripts/compare_tuned_xgboost_missingness.py  # 결측 처리·젖산 5조건
python scripts/analyze_lactate_subgroup_calibration.py
python scripts/compare_xgboost_indicators_icu.py     # 결측 지시변수 제거·첫 ICU 유형 추가
```

### 보고서 집계 · 그림 · 대시보드 (`final-dashboard/`)

```powershell
cd final-dashboard
..\.venv\Scripts\python train.py                 # 최종 모델 저장 + 입력 변환 검증 (약 15초)
..\.venv\Scripts\python report_extras.py         # 테스트 부트스트랩 95% CI, 기준별 분류표, 테스트 곡선(영어)
..\.venv\Scripts\python report_tables.py         # 대상자 특성표·제외군 비교·교차검증 ±SD·결론 숫자
..\.venv\Scripts\python report_model_ci.py       # 세 모델 비교: 교차검증 예측 차이의 95% CI (약 2분)
..\.venv\Scripts\python report_lactate_ci.py     # 젖산 수치 vs 측정 여부만: 교차검증 예측 차이의 95% CI (약 2.5분)
..\.venv\Scripts\python make_schematic.py        # 연구 모식도
..\.venv\Scripts\python make_flowchart.py        # 코호트 선정 흐름도 (인원은 데이터에서 셈)
..\.venv\Scripts\python make_test_curves_ko.py   # 테스트 곡선 한국어판
..\.venv\Scripts\python app.py                   # 교육용 대시보드 (Gradio)
```

`report_*.py`와 그림 스크립트는 결과가 팀 기록과 같을 때만 파일을 만듭니다(최종 모델 성능은 소수 여섯째 자리까지,
젖산 비교는 폴드별 차이까지, 세 모델 비교는 폴드 평균까지. 단 로지스틱 회귀는 소수 다섯째 자리 이하 차이 허용).
결과는 모두 `final-dashboard/outputs/`에 저장되며 환자 단위 자료는 저장하지 않습니다.
