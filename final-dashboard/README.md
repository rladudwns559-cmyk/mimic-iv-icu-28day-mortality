# ICU 28일 사망 위험 대시보드

팀 최종 모델(XGBoost · 대치 없음 + 결측 지시변수 + 젖산 + 첫 ICU 유형, 입력 150개)을 불러 쓰는 Gradio 대시보드입니다.
**교육용 연구 모델이며 실제 진료에 사용할 수 없습니다.**

## 폴더 구성

```
final-dashboard/
├── CLAUDE.md              규칙 파일
├── dashboard_core.py      화면 입력 → 모델 입력 150개 변환, 예측, 요인 분석 (train.py와 app.py가 함께 씀)
├── dashboard_core.js      dashboard_core.py와 같은 규칙의 브라우저용 계산 (HTML 파일용)
├── train.py               최종 모델 재학습 · 팀 기록과 대조 · 대시보드 자료 저장
├── app.py                 대시보드 화면 (모델을 다시 학습하지 않음)
├── build_html.py          팀원 전용 HTML 파일 만들기
├── report_extras.py       보고서 표 3·표 4·그림 3: 테스트 부트스트랩 95% CI, 기준별 분류표, ROC·PR·보정 곡선
├── report_tables.py       보고서 표 1·표 2(± SD)·표 5와 결론 숫자
├── report_model_ci.py     보고서 4.2: 세 모델 비교 차이의 95% CI
├── report_lactate_ci.py   보고서 4.2: 젖산 수치 vs 측정 여부만 차이의 95% CI
├── make_schematic.py      보고서 그림 1 연구 모식도
├── make_flowchart.py      보고서 그림 2 코호트 선정 흐름도
├── make_test_curves_ko.py 발표자료용 테스트 곡선 (그림 3의 한국어판)

    ├── metrics.csv        테스트 성능 지표

    ├── dashboard_screenshot.png  가상 환자 A(81.8%) 계산 화면 (보고서 그림 C1의 원본)
    └── report_extras/     보고서 집계(csv)와 그림
```

보고서 집계를 다시 만들려면 `train.py`를 실행한 뒤 저장소 README의 순서대로 `report_*.py`와 그림 스크립트를 실행합니다.

## 실행 순서 (팀원 컴퓨터에서 처음 실행할 때)

학습된 모델(`outputs/model.ubj`)과 `assets.json`은 MIMIC-IV 제한 데이터에서 나온 결과라서 팀 공유 zip에 넣지 않았습니다.
각자 본인의 PhysioNet 권한으로 받은 데이터에서 `train.py`를 한 번 실행하면 같은 모델이 만들어집니다(1분 이내).

1. `final-dashboard` 폴더를 팀 공유 폴더 `MIMIC_IV_팀공유` 안에 넣습니다.
2. 팀 README 순서대로 데이터를 만들어 둡니다. 필요한 파일은 `data/processed/error_cleaned/splits/`와 `data/raw/icustays.csv`입니다.
3. `MIMIC_IV_팀공유` 폴더에서 아래를 차례로 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -r final-dashboard\requirements.txt
cd final-dashboard
..\.venv\Scripts\python train.py
..\.venv\Scripts\python app.py
```

이미 `.venv`가 있으면 첫 줄은 건너뜁니다. `train.py`가 끝날 때 아래 확인 숫자와 같은 값(테스트 ROC-AUC 0.8189, 가상 환자 A 81.8%, B 1.5%)이
나와야 하며, 팀 기록과 다르면 실행이 멈추고 이유를 알려 줍니다.
그다음부터는 `app.py`만 실행하면 됩니다. 브라우저에서 `http://127.0.0.1:7860`을 엽니다.

대시보드는 각자 컴퓨터에서만 열립니다(`127.0.0.1`). 인터넷 공유 링크 기능은 넣지 않았습니다.

### 팀원 전용 HTML 파일 (설치·서버 없이 보기)

```powershell
..\.venv\Scripts\python build_html.py
```

`outputs/ICU_28일_사망위험_대시보드_팀원전용.html` 한 파일이 만들어집니다. 더블클릭하면 브라우저에서 열리고, 인터넷 없이도
값을 넣어 계산할 수 있습니다(환자 위험 평가 · CSV 일괄 예측 · 모델 정보).

- 저장된 모델(`model.ubj`)과 `assets.json`을 그대로 넣고, 계산은 `dashboard_core.js`가 `dashboard_core.py`와 같은 규칙으로 합니다.
- 가상 환자 402명으로 파이썬 대시보드와 비교해 오류·안내 문구와 입력 150개가 모두 같고, 예측 확률 차이 최대 0.00005%p,
  요인(SHAP) 차이 최대 0.0000013이었습니다. 확인 숫자: A 81.8%, B 1.5%.
- **모델이 파일 안에 들어 있으므로 PhysioNet 권한이 있는 팀원에게만 보냅니다.** 공개 게시판·단체방에 올리지 않습니다.
  (팀원 공유 zip에는 넣지 않았습니다.)

화면은 컴퓨터가 다크 모드여도 항상 밝은 테마로 열립니다. 주소 끝에 `?__theme=light`가 자동으로 붙는 것은 정상입니다.
다크 모드에서는 일부 글자가 배경과 같은 색이 되어 읽기 어렵기 때문에 밝은 테마로 고정했습니다(`app.py`의 `HEAD`).

## 화면 구성

- **환자 위험 평가**: 나이·성별·첫 ICU 유형 + 활력징후 7종·혈액검사 12종의 첫 24시간 최저·평균·최고·측정 횟수
  - 결과: 예측 확률, 위험 수준(낮음 <15% · 보통 15~30% · 높음 ≥30%), 평균 사망률 대비 배수, 테스트 환자 중 위치,
    비슷한 예측을 받은 테스트 환자의 실제 사망률, 경보 기준 30%·50% 해당 여부와 그 기준의 민감도·오경보율
  - 이 환자의 위험 요인(SHAP, 변수별 합산)과 입력 안내(범위 밖 값, 비운 측정 횟수, 미측정 검사)
- **여러 환자 한 번에 (CSV)**: 양식 내려받기 → 채워서 올리기 → 환자별 확률·위험 수준·주요 요인 표와 결과 파일
- **모델 정보·한계**: 성능 지표 해석, ROC·PR 곡선, 확률 보정 그래프, 경보 기준별 성능표, 한계 5가지

## 입력 규칙

- 검사를 하지 않았으면 칸을 모두 비웁니다 → 미측정(측정 횟수 0, 결측 지시변수 1)으로 계산합니다.
- 값이 하나뿐이면 최저=평균=최고로 봅니다. 평균을 비우면 최저와 최고의 중간값을 씁니다.
- 측정 횟수를 비우면 학습 환자에서 그 변수를 잰 사람의 중앙 횟수를 씁니다.
- 표준편차는 (최고 − 최저) ÷ k로 추정합니다. k는 학습 데이터에서 계산한 변수별 중앙 비율입니다.
- 물리적으로 불가능한 값, 최저 > 최고, 1회 측정인데 값이 서로 다른 경우는 계산하지 않고 오류로 알립니다.
